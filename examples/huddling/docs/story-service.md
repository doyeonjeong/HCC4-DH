# 허들링 앱 서비스 맥락

> 기준: docs/prd.md의 MVP 1차

## 사용자 스토리

1. 무료 학습자가 공개 학습자료를 둘러보고 유료 자료의 미리보기를 확인한다.
2. 유료 멤버가 강의자료와 스킬·프롬프트를 찾아 사용한다.
3. 멤버가 월간 미션 산출물을 제출하고 제출 상태를 확인한다.
4. 판매 승인 회원이 자신의 자산을 등록하고 판매 검수를 신청한다.
5. 운영자가 판매 기준 체크리스트로 신청을 검수하고 승인·수정 요청·반려를 결정한다.

## 이 서비스에서 어기면 안 되는 것

1. `sale_requested`는 운영진이 수동 승인한 `seller` 역할만 선택할 수 있다.
   MVP 검수에는 운영자 체크리스트가 필수이며 AI 1차 검수는 포함하지 않는다.
2. MVP의 승인 경로는 `approved`에서 끝난다.
   `for_sale`·`suspended` 상태와 구매·결제·정산 흐름은 노출하지 않는다.
