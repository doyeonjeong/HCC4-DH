# R5 — 게이트와 통과 조건

`rules.yaml`이 검사 기준의 단일 출처입니다. 선택한 프리셋의 화면 크기, 안전 영역, 최소 조작 목표 크기는 `presets/<preset>.yaml`에서 가져옵니다.

| 게이트 | 방식 | 기본 확인 |
| --- | --- | --- |
| G1 시스템 페이지 | 기계 | 변수 연결, 오토레이아웃, 텍스트 크기 조절·정렬, 최소 목표 크기, 필수 컴포넌트, 개수·변형 축 |
| G2 화면 페이지 | 기계 | G1 기준, 인스턴스 사용, 화면별 주 동작 수, 대비, 안전 영역 바인딩, 프로젝트 불변조건 |
| G3 승인 | 사람 | 화면 흐름, Figma 링크, G1/G2 요약과 규칙 해시 확인 |
| P4 시각 QA | 사람 검토 | 데스크톱과 360px Chrome 캡처를 Figma와 비교하고 R4 체크리스트를 기록 |

G1/G2는 `tools/build-figma-gate.mjs`가 만든 번들을 Figma 안에서 실행합니다. 번들이 덤프와 `evaluate.js` 판정을 한 번에 수행하고, 원문 텍스트나 전체 덤프 대신 제한된 요약만 반환해야 합니다. 결과 크기는 20KB 미만으로 유지합니다.

화면 제목과 섹션 라벨은 `Heading` 컴포넌트를 기본으로 사용합니다. 상단 안전 영역은 `safe-area.top` 변수로 만들고 화면 프레임의 `paddingTop`에 연결합니다. 안전 영역이 0인 웹 프리셋에서는 해당 바인딩을 요구하지 않습니다.

동일한 게이트가 3회 연속 실패하면 더 시도하지 말고 현재 증거, 변경 내용, 막힌 이유를 보고합니다. 게이트를 건너뛰거나 과거 승인 결과를 재사용하지 않습니다.
