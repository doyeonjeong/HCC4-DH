# R4 — 산출물

각 단계 결과는 `runs/<run-id>/`에 보관합니다. 제품 기준 문서는 `docs/`, 게이트 기준은 `rules.yaml`과 선택한 프리셋에 둡니다.

- P1: 선택한 흐름, 사용자 역할·이야기, 범위, 불변조건
- P2: 출처가 기록된 UI 레퍼런스, 토큰, 컴포넌트 명세, Figma 시스템 페이지
- G1: Figma 덤프와 요약 판정
- P3: 화면 목록, 핵심 상태, Figma 화면 페이지
- G2: Figma 덤프와 요약 판정
- G3: 승인자, 시각, 승인된 규칙 해시와 판정 요약
- P4: HTML 프로토타입, 화면별 데스크톱·360px 스크린샷, Figma 비교 결함 표

P4 결함 표에는 화면, 뷰포트, 관찰 내용, 재현 방법, 심각도, 조치 상태를 기록합니다. 아래 항목을 모두 확인합니다.

- 버튼이나 텍스트가 잘리는가
- 고정 헤더, CTA, 탭바가 콘텐츠를 가리거나 겹치는가
- 같은 요소나 콘텐츠가 중복 표시되는가
- 한국어 줄바꿈이 단어 중간에서 부자연스럽게 끊기지 않는가 (`word-break: keep-all` 포함)
- 토스트가 주요 콘텐츠나 조작 요소를 가리는가
