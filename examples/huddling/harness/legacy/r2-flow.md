# R2 — 목적

## 목적 한 문장

허들링 디자이너가 허들링 MVP의 선택한 사용자 흐름을 입력하면, Codex 디자인 하네스가 PRD와 디자인 원칙에 맞는 Figma 핵심 화면 3개와 UI Bowl 참고 근거를 만들고 기계 검수 후 Public 제출 준비 상태로 만든다.

## 매 실행마다 달라지는 것

- `docs/prd.md`에서 선택하는 MVP 사용자 흐름과 그 흐름에 속한 화면
- 첫 PoC 기본 흐름: 무료 학습자료 목록 → 스킬/프롬프트 상세 → 월간 미션 제출

## 사용자

- 하네스 사용자: 허들링 앱을 기획·디자인하는 디자이너
- 실행 도구: Codex 하네스
- 서비스 사용자: 무료 학습자, 유료 멤버, 판매 승인 회원, 운영자 (`docs/story-service.md` 참조)

## 완료 기준

- Figma에 위 흐름의 핵심 화면 3개가 존재한다.
- 화면 설명과 UI Bowl 읽기 전용 참고 링크가 산출물에 기록된다.
- PRD 불변 조건에 대한 자동 게이트를 통과하거나 실패 사유가 기록된다.
- Public 제출용 링크와 요약이 준비된다. 실제 공개 제출은 G5 승인을 기다린다.

## 작업 방식 전제

R1-B에서 과거 AI 없는 수작업 기준 흐름은 확인되지 않았다. 따라서 이 목적은 과거 작업의 자동 재현이 아니라, 위 PoC 사용자 흐름을 앞으로 일관되게 디자인하는 하네스 목표다.
