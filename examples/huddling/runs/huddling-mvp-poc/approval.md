# 디자인 시안 승인 — 사람만 작성

- 실행: `huddling-mvp-poc`
- Figma 파일: https://www.figma.com/design/DF7XZVnPQqcqobaKgPJy98
- 입력 지문: (검수 스크립트가 계산한 값을 붙여 넣기)
- 선택 시안: (시안 ID)
- Public 제출 여부: Codex가 실행하지 않음. 최종 제출은 사용자가 직접 진행.
- `APPROVED: yes` 또는 `APPROVED: no`
- 승인자:
- 승인 시각:

현재 입력 지문과 시안을 사람이 확인한 뒤 승인 값을 작성한다. 입력이 바뀌면 재승인한다.
에이전트는 이 문서의 승인 값이나 승인자 정보를 변경하지 않는다.
